PROJECT SHADOW PWA — BUILD 01

Incluye panel principal, misiones editables, XP y niveles automáticos, atributos iniciales, historial y exportación/importación de copias de seguridad.

Para probar:
1. Descomprime el ZIP.
2. Para usar como web, abre index.html.
3. Para instalar como PWA, publica los archivos en un alojamiento HTTPS.
4. En iPhone abre la dirección en Safari > Compartir > Añadir a pantalla de inicio.

Los datos se guardan localmente en el navegador. No existe aún sincronización entre dispositivos ni cuentas. Exporta una copia de seguridad periódicamente.
